Why Order Emails Matter

Order confirmations are among the most opened emails a store sends. They reassure the customer, cut "where is my order?" support tickets and are a chance to show your brand and recommend the next purchase.

Shopify's default template is clean and works, but it looks the same as thousands of other stores. A few careful changes make it feel like part of your brand, without risking the data that customers rely on.

Step by Step

  1. Brand settings: in Notifications, click Customize email templates to set your logo, logo width and accent colour. This updates all notifications.
  2. Open the template: Customer notifications, Order confirmation, Edit code.
  3. Back up the code by copying it into a text file before changing anything.
  4. Edit the HTML and CSS for layout, fonts and spacing. Keep all Liquid tags and loops.
  5. Preview with Shopify's sample data, then place a real test order to check discounts, shipping and taxes.
  6. Repeat for the shipping, delivery and refund notifications so all emails match.

Menu names in Shopify admin change from time to time. If you cannot find a label, search "notifications" in the admin search bar.

Understanding Liquid in Two Minutes

Shopify notifications use Liquid, a simple template language. There are two kinds of tags:

  • Output tags use double curly braces, such as {{ order_name }}. They print a value, like "#1042".
  • Logic tags use curly braces with percent signs, such as {% if %} and {% for %}. They decide what shows and repeat blocks.

Filters change how a value looks. For example, {{ total_price | money }} formats a number as currency. You can freely change the HTML around these tags. Problems start when a tag is deleted, or when an opening tag like {% if %} loses its closing {% endif %}.

Liquid Tags You Must Keep

  • {% for line in subtotal_line_items %} and its closing tag, which lists the products.
  • {{ order_name }}, {{ subtotal_price | money }}, {{ total_price | money }}.
  • Shipping and billing address blocks, and the order status link {{ order_status_url }}.
  • Conditions like {% if discounts %} that show discounts only when they apply.

Example: Restyling a Product Row

Inside the line-item loop, you can change the table markup around each product while keeping the data tags. A simple row might be:

<tr><td width="80"><img src="{{ line.image | img_url: 'compact_cropped' }}" width="64" alt="{{ line.title }}"></td><td>{{ line.title }} × {{ line.quantity }}</td><td align="right">{{ line.final_line_price | money }}</td></tr>

Copy the exact variable names from your existing template rather than from this example. Shopify's default code may use slightly different names or filters, and those are the ones that are known to work in your store.

Keeping the Whole Set Consistent

Customers see more than one email after they buy. A typical order sends a confirmation, a shipping update, sometimes a delivery notice and, now and then, a refund or cancellation email. If only the first one is branded, the others feel like they come from a different company.

A good way to keep them consistent is to build one shared header and footer and paste the same code into each notification. Keep a single master file with those pieces. When your logo or address changes, update the master file first, then copy it into each notification. Write down which notifications you have changed, so nothing is missed.

Which Notifications to Prioritise

  • Order confirmation: sent for every order, so start here.
  • Shipping confirmation: the second most seen, and it holds the tracking link.
  • Order cancelled and refund: sent less often, but tone matters when something goes wrong.
  • Abandoned checkout: if you use Shopify's version instead of a separate email platform.

Common Mistakes

  • Deleting an {% endif %} or {% endfor %}, which can break the whole email.
  • Testing only with sample data. Real orders with discounts, gift cards or local pickup can show blocks you never saw.
  • Using CSS that email clients do not support, such as flexbox for the main layout.
  • Adding large images that load slowly or fail. See why email images are not showing.
  • Putting a big promotion above the order details, which confuses customers.
  • Updating the order confirmation but leaving shipping and refund emails in the old style.

Ideas to Improve Them

  • A clear order summary with product images.
  • Help links: shipping times, returns, contact.
  • A small upsell or "complete the look" block, kept below the order details.
  • A dark mode friendly logo. See our dark mode guide.
  • A short thank-you line in your brand voice.
  • A large, easy-to-tap "View your order" button linked to the order status page.

A Real-World Scenario

A small clothing store edits its order confirmation to add a new header and a "you might also like" block. The preview looks good. A week later, a customer who used a discount code writes in: the email showed no total. The developer finds that an {% endif %} was removed during the edit, which hid the totals block for discounted orders. They restore the tag from the backup, move the upsell below the totals, and place real test orders with and without discounts before saving. This is why backups and real test orders matter.

Frequently Asked Questions

Can I edit Shopify order confirmation emails?

Yes. Go to Settings, Notifications, open the notification and click Edit code. You can change the HTML and CSS freely.

Will editing the code break my order emails?

Not if you keep the Liquid tags and loops. Back up the original code and test with a real order after changes.

Can I use Klaviyo instead of Shopify notifications?

Klaviyo can send some order-related emails, but Shopify notifications are still used for core confirmations unless you set up a full replacement. Our comparison of Klaviyo vs Mailchimp for Shopify covers the wider choice.

How do I restore the default Shopify template?

Paste back the code you saved before editing. Shopify has also offered a revert option in the code editor; check the current admin for it.

Can I add product recommendations to the order email?

Yes, but keep them below the order details and keep them simple. The main job of this email is to confirm the order.
