Short answer: Gmail does not accept raw HTML code in its signature box. To add an HTML signature, open the signature in a web browser, select it, copy it, and paste it into Settings > See all settings > General > Signature. Images must be hosted online (not attached), and the signature must be under Gmail's 10,000-character limit.

Before You Start

  • Have your signature as an .html file or a web page link.
  • Make sure every image (logo, photo, icons) is hosted on a public URL, not embedded or attached. Gmail removes embedded images.
  • Use Gmail on a computer. The Gmail mobile apps only support plain text signatures.
  • Check which account you are in. If you use several Gmail or Google Workspace accounts, each one has its own signature settings.

How to check that images are hosted

Open the .html file in a text editor and look at each image tag. A hosted image looks like <img src="https://example.com/logo.png" width="120" alt="Company logo">. If the src starts with data:image, cid: or a local path such as C:\, the image will not survive in Gmail. Upload it to your website or another public host and update the link.

Step-by-Step: Add the Signature in Gmail

  1. Open the signature file in Chrome or another browser (double-click the .html file, or open the link you were given).
  2. Select the whole signature with your mouse, or press Ctrl+A (Windows) or Cmd+A (Mac).
  3. Copy it with Ctrl+C or Cmd+C.
  4. In Gmail, click the gear icon, then See all settings.
  5. On the General tab, scroll to Signature and click Create new. Give it a name.
  6. Paste the signature into the box with Ctrl+V or Cmd+V.
  7. Under Signature defaults, choose it for new emails and for replies and forwards.
  8. Scroll to the bottom and click Save Changes.
  9. Send a test email to yourself and to a colleague who uses Outlook, and check it on a phone.

Tip: if the file opens with a white page and lots of empty space, select only the signature area by dragging from the top-left corner of the signature to the bottom-right. Selecting the whole page sometimes copies extra blank lines.

Optional: turn off the dashes

Gmail can insert "--" above your signature. If you do not want it, find the option in the same Signature section to place the signature before quoted text and adjust how it appears in replies. The exact wording of these settings can change, so look for it near the signature defaults.

Fixing Common Gmail Signature Problems

Images do not show

The images are probably embedded or attached. Host them online (your website, or a storage service with public links) and make sure the signature's HTML points to those URLs. If the links are correct but images still do not load for some recipients, their email client may block images by default. Our guide on why email images are not showing covers the other causes.

"Signature is too long" error

Gmail limits signatures to 10,000 characters of code. Remove unused styles, shorten tracking links, and avoid copying extra page content. A well-coded signature is far under the limit.

The layout changes or spacing collapses

Gmail strips some CSS. Signatures should be built with tables and inline styles, which Gmail keeps. If yours was made in a word processor, it will not paste reliably.

Images look blurry

Use images exported at twice their displayed size and set a fixed width in the HTML, so they look sharp on retina screens.

The signature looks different in Outlook

Your recipients' email client renders the signature, not Gmail. A signature built only for Gmail can break in Outlook. See our guide on adding an HTML signature in Outlook and how cross-client HTML signatures are built.

Icons or logo vanish in dark mode

Dark logos and black social icons can disappear when the recipient uses dark mode. Use icons with a light outline or a coloured background. Our dark mode email design guide explains the options.

What a Gmail-Safe Signature Looks Like in Code

A reliable signature uses a simple table, inline styles and hosted images with fixed widths. A trimmed example:

<table cellpadding="0" cellspacing="0" border="0"><tr><td style="padding-right:12px;"><img src="https://example.com/photo.png" width="80" alt="Jane Doe"></td><td style="font:14px/20px Arial,sans-serif;color:#333333;"><strong>Jane Doe</strong><br>Head of Sales</td></tr></table>

No external stylesheet, no div-based layout, no background images and no web fonts. Those are the features Gmail and Outlook handle poorly in signatures.

Common Mistakes

  • Pasting the HTML code itself into the signature box, which shows the code as text.
  • Using a signature image (one big picture of the whole signature). It looks blank when images are off and the text cannot be clicked.
  • Forgetting to set the default for replies, so replies go out without a signature.
  • Linking images from a private folder, such as a Google Drive file that needs a login.
  • Adding too many social icons and banners, which pushes the signature past the character limit.

Frequently Asked Questions

Can I paste HTML code into a Gmail signature?

No. Gmail's signature box does not accept code. Open the HTML signature in a browser, copy the rendered signature, and paste it into Gmail.

Why are the images missing from my Gmail signature?

Gmail removes embedded and attached images. Host each image online and make sure the signature points to those public image URLs.

Can I use an HTML signature in the Gmail mobile app?

The Gmail app only supports plain text signatures. If no mobile signature is set, it can use your desktop signature depending on your settings, so always check how emails sent from your phone look.

Can I have different signatures for new emails and replies?

Yes. Create two signatures in the Signature section and choose one for new emails and a shorter one for replies and forwards under Signature defaults.

Will the same signature work in Outlook?
