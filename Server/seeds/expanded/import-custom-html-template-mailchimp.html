Short answer: in Mailchimp, go to Content, Email templates, Create template, Code your own, then choose Import HTML and upload your .html file or a .zip with the HTML and images. To let your team edit text and images later, the template needs Mailchimp's editable tags (such as mc:edit) added before import. Without them, every change means editing code.

Before You Import: Prepare the Template

  • Host images online or include them in the .zip. Local paths like C:/images/logo.png will break.
  • Add editable regions: put mc:edit="header_text" on text blocks and images your team will change. Each name must be unique.
  • Add repeatable blocks with mc:repeatable and mc:variant if you want to add or swap sections, like product rows.
  • Keep required merge tags: the footer must include *|UNSUB|* and your address tags, or Mailchimp will warn you.
  • Keep code lean. Heavy code can trigger Gmail clipping at 102 KB.
  • Inline your CSS. Mailchimp can inline CSS for you, but checking it yourself avoids surprises.

How Mailchimp's Template Language Works

Mailchimp reads special attributes in your HTML to decide what users can edit in the drag-and-drop editor. Here are the ones you will use most:

AttributeWhat it doesExample use
mc:editMakes text or an image editableHeadline, body copy, hero image
mc:repeatableLets users duplicate or remove a blockProduct rows, article blocks
mc:variantOffers alternative layouts for a repeatable blockImage left or image right
mc:hideableLets users hide a block without deleting itOptional banner

Example: An Editable Text Block

<td mc:edit="intro_text" style="font-family:Arial, sans-serif; font-size:16px;">Write your intro here.</td>

Example: An Editable Image

<img mc:edit="hero_image" src="https://example.com/hero.jpg" width="600" alt="Spring sale" style="display:block; max-width:100%; height:auto;">

Example: A Repeatable Product Row

<table mc:repeatable="products" mc:variant="Image left"> ... </table>

Put mc:edit on the elements inside the repeatable block too, so each copy can hold different content. Check Mailchimp's current template language docs, as supported attributes can change.

Step by Step: Import Into Mailchimp

  1. Open Content, then Email templates.
  2. Click Create template and choose Code your own.
  3. Select Import HTML and upload the .html or .zip file.
  4. Name the template and save it.
  5. Create a new email campaign and choose the template under Saved templates.
  6. Click each editable area to confirm it can be changed without code.
  7. Send a test to Gmail and Outlook before using it for real.

Mailchimp moves menu items from time to time. If a label has changed, look for the templates area and an option to code or upload your own.

Planning Editable Areas With Your Team

Before adding tags, sit down with the people who will build campaigns. Ask them which parts change every send and which parts should never move. A good template gives them freedom where they need it and locks everything else.

  • Usually editable: headline, intro text, hero image, button text and link, product blocks and article blocks.
  • Usually locked: the header logo, the main layout tables, the footer structure and legal text.
  • Optional: banners and promo strips, marked as hideable so they can be switched off.

Give each mc:edit a clear name, such as hero_headline or product_1_price. Clear names make the template easier to maintain and easier to hand to a new team member. Also write a one-page guide that lists each editable area and its limits, such as the best image size or the maximum headline length. That guide prevents most of the layout problems that appear after launch.

Version Control

Keep the master HTML file outside Mailchimp, with a date in the file name. When you need a change, edit the master and re-import it as a new template. This way, you always have a clean copy to go back to.

Common Mistakes

  • Using the same mc:edit name twice, which makes Mailchimp mix up content.
  • Placing mc:edit on a table that holds the layout, so users can delete the structure by accident.
  • Editing the code after import without keeping a master copy outside Mailchimp.
  • Forgetting the footer merge tags, which blocks sending.
  • Uploading a .zip with images in nested folders that do not match the paths in the HTML.

Frequently Asked Questions

Can I upload my own HTML template to Mailchimp?

Yes. Use Content, Email templates, Create template, Code your own, then Import HTML. You can upload a single .html file or a .zip that includes images.

Why can’t I edit my imported Mailchimp template?

The template has no Mailchimp editable tags. Add mc:edit attributes to text and image areas, then import it again.

Does Mailchimp support responsive custom templates?

Yes. Mailchimp sends your HTML as it is, so a well-built responsive template stays responsive.

Can I use a custom template with Mailchimp's new builder?

At the time of writing, custom-coded templates open in the classic editor. Check Mailchimp's current help pages, as this may change.

Can I let my team add or remove sections?

Yes. Mark those sections with mc:repeatable and, if needed, mc:variant for different layouts.
