Short answer: classic Outlook for Windows uses Microsoft Word to display emails, and Word ignores CSS background images. To show a background image there, add VML (Vector Markup Language) code inside Outlook-only conditional comments. Always set a solid background colour as a fallback and keep the text on top as live HTML text.

Why Outlook Drops Background Images

Outlook 2007 to 2021 and Microsoft 365 for Windows render HTML with the Word engine. It does not support background-image in CSS, so hero images with text on top show as a plain colour or a blank area. Apple Mail, Gmail, new Outlook and Outlook on the web show them normally.

This matters most for hero sections: a photo with a headline and a button on top. In classic Outlook, the photo vanishes. If the text is white and the fallback colour is also white, the headline disappears too. The reader sees an empty block at the top of your email. The difference between new and classic Outlook explains why the two versions behave so differently.

How the VML Fix Works

  1. Set the background image in CSS and with the background attribute on the table cell, for most clients.
  2. Inside <!--[if gte mso 9]> comments, add a v:rect with a v:fill that uses the same image, and a v:textbox to hold the content.
  3. Set the VML width and height in pixels; VML does not understand percentages well.
  4. Close the VML elements inside a matching <![endif]--> block after your content.
  5. Add the VML namespace to the <html> tag: xmlns:v="urn:schemas-microsoft-com:vml".

A Working Code Example

Here is the basic pattern for a 600 by 300 px hero. First, the table cell for most clients:

<td background="https://example.com/hero.jpg" bgcolor="#2b3a55" width="600" height="300" valign="top" style="background:url('https://example.com/hero.jpg') center / cover no-repeat #2b3a55;">

Then the Outlook-only VML that opens right inside the cell:

<!--[if gte mso 9]><v:rect xmlns:v="urn:schemas-microsoft-com:vml" fill="true" stroke="false" style="width:600px;height:300px;"><v:fill type="frame" src="https://example.com/hero.jpg" color="#2b3a55" /><v:textbox inset="0,0,0,0"><![endif]-->

Next comes your normal HTML content: the headline, text and button. Finally, close the VML before the cell ends:

<!--[if gte mso 9]></v:textbox></v:rect><![endif]--></td>

The color on v:fill is the Outlook fallback colour. The bgcolor and CSS colour are the fallback for everyone else.

With frame, export the image at the same ratio as the VML shape, or it will look stretched.

Rules for Safe Background Images

  • Always set a background colour close to the image's main colour, so text stays readable if the image fails.
  • Keep text as live text, not baked into the image.
  • Use fixed heights carefully: too little height cuts content off in Outlook.
  • Use it only where it matters, like the hero. VML adds code weight and counts toward the 102 KB Gmail limit.
  • Use absolute image URLs. Relative paths break once the email leaves your server.
  • Keep the image file small. A large hero slows loading on mobile data.

When Not to Use a Background Image

VML works, but it is not always the best answer. Sometimes a simpler layout gives the same result with less risk. Consider these options first:

  • Stack the image and text. Put the photo as a normal image and the headline below it on a solid colour. This works in every client with no VML at all.
  • Use a solid colour block. A strong brand colour behind the headline can look just as good and loads faster.
  • Use the image only on wider screens. On phones, a background image with text on top often gets cramped. Many teams hide it on mobile and show a plain colour instead.

Use a VML background when the design truly needs text over a photo, and when Outlook is a meaningful part of your audience. If your reports show very few classic Outlook opens, a clean fallback colour may be enough.

Working With Email Builders

Some platforms clean up code on import and may remove conditional comments or the VML namespace. After you paste or upload your template, send a test to classic Outlook straight away. If the image is missing, check whether the VML survived in the saved version of the code.

Common Mistakes

  • Forgetting the namespace on the <html> tag, so Outlook ignores the VML.
  • Opening the VML in one conditional block and never closing it, which can break the rest of the email in Outlook.
  • Using different image URLs in the CSS and VML, then updating only one.
  • Setting a VML height smaller than the content, so text is cut off.
  • Choosing a light fallback colour behind white text.
  • Letting an email builder strip the conditional comments when you paste the code in.

DPI Scaling and Dark Mode

On Windows laptops with display scaling above 100%, classic Outlook can scale VML shapes differently from the HTML around them. This can leave small gaps or a shifted image. Adding the Office settings block with o:PixelsPerInch set to 96 in the head helps keep sizes consistent. Dark mode is another risk: Outlook may change the fallback colour and text colour. Quick Checklist

  • VML namespace added to the html tag.
  • Image URL is absolute and the same in CSS and VML.
  • Fallback colour set in three places: bgcolor, CSS and v:fill.
  • Width and height in pixels, tall enough for all content.
  • Tested in Outlook 2016, 2019, Microsoft 365 and new Outlook.
  • Tested with images off.

Frequently Asked Questions

Does Outlook support background images in emails?

Classic Outlook for Windows does not support CSS background images. Use VML inside conditional comments. New Outlook and Outlook on the web support CSS backgrounds.

What is VML in email?

VML is an old Microsoft vector format that the Word rendering engine understands. Email developers use it for background images and rounded buttons in Outlook.

Will VML affect other email clients?

No. VML sits inside Outlook-only conditional comments, so other clients ignore it.

Why is my VML background image stretched?

With type="frame", the image stretches to the shape size. Export the image at the same width-to-height ratio as the VML shape.

Can I use a background image on the whole email?

You can, but it is risky. Full-body VML is harder to control and adds weight. Most teams limit background images to the hero or one banner.
