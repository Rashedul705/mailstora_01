HubSpot's built-in email themes are quick to start with, but they limit how far you can go with brand design. A custom coded template gives you full control over the HTML while keeping the editor friendly for your team. This guide covers when to build one, the exact steps, sample HubL, common errors and how to keep the template easy to maintain. Menu names can change, so check HubSpot's current docs if a label looks different in your portal.

When You Need a Custom Coded Template

  • Your brand design cannot be built with the default themes.
  • You need exact control over Outlook and mobile rendering.
  • You want a set of reusable, locked brand modules for your team.
  • You send many email types (newsletter, product update, event invite) and want them to share one system.

Step by Step

  1. Open Design Tools and create a new coded email template.
  2. Paste your tested, table-based HTML layout.
  3. Add editable modules with HubL, for example {% module "hero_text" path="@hubspot/rich_text" %}.
  4. Or add a {% dnd_area %} so marketers can drag, drop and reorder sections.
  5. Build custom modules for repeated sections such as product cards or event details.
  6. Add required tags such as {{ unsubscribe_link }} and the company address.
  7. Publish, create a test email from the template and send tests to Outlook, Gmail and mobile.

A Minimal Template Skeleton

Here is the basic shape of a coded template. It starts with template annotations that tell HubSpot this is an email template:

<!-- templateType: email isAvailableForNewContent: true label: Brand Newsletter -->

Then a table-based wrapper, with modules in the editable spots:

<table role="presentation" width="100%" cellpadding="0" cellspacing="0"> <tr><td align="center"> <table role="presentation" width="600"> <tr><td>{% module "logo" path="@hubspot/image_email" label="Logo" %}</td></tr> <tr><td>{% module "hero_text" path="@hubspot/rich_text" label="Hero text" %}</td></tr> <tr><td>{{ site_settings.company_name }} {{ unsubscribe_link }}</td></tr> </table> </td></tr> </table>

Check the current HubSpot documentation for the exact names of required tags and default modules in your portal, as these are updated from time to time.

Building Custom Modules

Custom modules are reusable blocks with their own fields. A product card module might have fields for image, title, price, and button text and URL. In the module's HTML you reference fields like {{ module.title }} and {{ module.button_url }}. Keep the HTML inside each module table-based and inline-styled, just like the main template, so it renders in Outlook. Common Problems

  • Template won't publish: required tags are missing.
  • Editor shows no editable content: the template has no modules or dnd area.
  • Outlook layout breaks: the HTML uses divs or flexbox. See Outlook fixes.
  • Gmail clips the email: modules add code; keep it under 102 KB. See Gmail clipping.
  • Buttons look different in Outlook: use bulletproof email buttons rather than styled links alone.
  • Colors flip in dark mode: test and plan for it. See dark mode email design.

Adding Personalization and Logic

HubL also lets you personalize content and show or hide blocks. A greeting with a fallback might look like this:

Hi {{ contact.firstname|default("there") }},

You can also show a block only to certain contacts, for example:

{% if contact.lifecyclestage == "customer" %} ... {% endif %}

Use logic with care. Every condition is one more thing to test, and a typo can hide a whole section. Keep logic simple, give every personalization token a fallback, and send test emails as contacts with and without the data filled in. HubSpot's preview tool lets you view the email as a specific contact, which is a quick way to check this before you send.

Testing Before You Go Live

  1. Create a test email from the template and fill every module with realistic content, including long headlines.
  2. Send tests to classic Outlook for Windows, new Outlook, Gmail web and app, Apple Mail and iPhone.
  3. Check dark mode, images turned off and a narrow phone screen.
  4. Check the size of the sent HTML against the Gmail limit.
  5. Click every link, including the unsubscribe and preferences links.

Frequently Asked Questions

Can I use custom HTML templates in HubSpot?

Yes. Create a coded email template in Design Tools. Add modules or a drag-and-drop area so it stays editable.

What is HubL?

HubL is HubSpot's template language. It adds modules, variables and logic to HTML templates.

Why won't my HubSpot email template publish?

Usually required tags are missing, such as the unsubscribe link or company address.

Can I convert a Figma design into a HubSpot template?
