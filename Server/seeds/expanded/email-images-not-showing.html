Short answer: email images usually fail to show for one of seven reasons: the reader's client blocks images by default, the image path is local or broken, the image is on an insecure (HTTP) server, the file is too large, the format is not supported, Outlook ignores the size or a background image, or a firewall blocks your image host. Most of these are fixed in the template code.

Missing images make an email look broken, even when everything else is fine. The reader sees empty boxes, a red cross or a long line of alt text where your product photo should be. The tricky part is that images often work for you and fail only for some readers. This guide explains each cause, how to spot it, and how to fix it.

7 Causes and Fixes

  1. Images blocked by default. Some Outlook setups and company inboxes block images until the reader allows them. Fix: never put key text only inside images, and always write useful alt text.
  2. Local or broken image paths. A path like file:/// or C:/ only works on your computer. Fix: host images online and use full https:// URLs.
  3. HTTP instead of HTTPS. Many clients block images from insecure servers. Fix: host every image on HTTPS.
  4. Files too large. Heavy images load slowly or time out on mobile. Fix: keep most images under 200 KB and size them at twice the display width for sharp screens.
  5. Unsupported formats. SVG and WebP do not work everywhere. Fix: use JPG, PNG or GIF for email.
  6. Outlook sizing and background images. Outlook ignores CSS width on images and CSS background images. Fix: set the width attribute on the image and use VML for backgrounds. See background images in Outlook.
  7. Blocked image hosts. Company firewalls can block some file-sharing services. Fix: host images on your email platform or your own domain, not on Google Drive or Dropbox.

To see the real image paths, open the sent email, view its source (in Gmail, "Show original"), and search for src=. Every path should start with https:// and point to a public server.

A Well-Built Image Tag

Most image problems disappear when every image in the template follows the same pattern. A safe image tag for email looks like this:

<img src="https://cdn.yourbrand.com/email/hero.jpg" width="600" alt="20% off all boots this weekend" style="display:block; width:100%; max-width:600px; height:auto; border:0;">

  • Full HTTPS URL on a reliable host.
  • width attribute so classic Outlook uses the right size.
  • Useful alt text that carries the message if the image is blocked.
  • display:block to remove the small gap some clients add under images.
  • max-width and height:auto so the image scales on phones.

Design for Images Off

  • Use live HTML text for headlines, offers and buttons.
  • Give images a background colour so the layout still holds its shape.
  • Write alt text that tells the story: "20% off all boots this weekend", not "banner1.jpg".
  • Make buttons from code, not images. See bulletproof email buttons.

Designing for images off also helps screen reader users and people on slow connections. Our accessible email design guide explains how to write alt text that works for both. Image-only emails can also hurt inbox placement, which we cover in why emails go to spam.

Common mistakes

  • Putting the whole email, including the offer and button, in one image.
  • Leaving the file name as alt text, or no alt text at all.
  • Linking to images in a shared Drive folder that needs a login.
  • Deleting old images from the server, which breaks past emails still in inboxes.
  • Using a dark logo on a transparent PNG, which can vanish in dark mode.

Why Images Look Huge in Outlook

A related complaint: an image looks right everywhere except classic Outlook for Windows, where it appears at its full original size, for example a small headshot turning into a giant 2000 px photo. Outlook ignores CSS width and max-width on images and uses the file's real size instead. The fix is to always set the HTML width attribute (for example width="80") on every image, and to resize the file close to twice its display size. On high-DPI Windows screens, Outlook can also scale images unexpectedly; adding the Office DPI settings in the head (o:PixelsPerInch set to 96) keeps sizes stable.

Frequently Asked Questions

Why are my email images not showing in Outlook?

Outlook may block images by default, ignore CSS image sizes or ignore CSS background images. Use width attributes, VML backgrounds and alt text.

Why do my images show in Gmail but not for some readers?

Those readers may have images turned off, or a company firewall may block your image host. Host images on HTTPS on your own domain or email platform.

What image format is best for email?

JPG for photos, PNG for logos and graphics with transparency, and GIF for simple animation. Avoid SVG and WebP in email.

Do large images cause Gmail clipping?

No. Gmail's 102 KB limit counts the HTML code, not image files. Large images slow loading, but clipping comes from heavy code. See our guide to Gmail clipping.

Why do old emails suddenly show broken images?

The images were probably deleted or moved on the server. Keep email images at stable URLs for as long as the emails may be opened.
